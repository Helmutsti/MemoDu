# Memodu

Archivia le idee. Organizza i testi.

Memodu è un'applicazione di note cross-platform che mette la scrittura al primo posto: si apre all'istante, si scrive in markdown e le note restano sincronizzate nel cloud con cifratura end-to-end. È pensata per chiunque abbia bisogno di prendere appunti o produrre documenti formattati.

## Avvio rapido
```bash
# Installazione
[comando]

# Avvio in locale
[comando]

# Test
[comando]
```
