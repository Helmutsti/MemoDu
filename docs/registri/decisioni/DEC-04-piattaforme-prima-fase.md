# DEC-04 – Piattaforme della prima fase

**Data:** 2026-09-24 · **Stato:** Superata da DEC-13 · **Idea di origine:** —

## Contesto
La visione chiede un'app cross-platform (RNF-06), ma senza indicare quali piattaforme. Ogni piattaforma in più moltiplica schermate, test e casi limite, e condiziona le scelte tecnologiche della Fase 7.

## Opzioni valutate
Qualsiasi combinazione di: Windows, macOS, mobile (iOS e Android), web (browser).

## Decisione
Nella prima fase Memodu gira su Windows, macOS e web (browser). Il mobile è rinviato.

## Conseguenze
- RNF-06: piattaforme definite.
- ID-11: app mobile parcheggiata, da rivalutare a fine prima fase.
- RF-01: sul web non esiste una scorciatoia globale di sistema, quindi il comportamento della nota rapida nel browser va definito.
- RF-12 (Should): le finestre sganciabili riguardano le app desktop Windows e macOS.
