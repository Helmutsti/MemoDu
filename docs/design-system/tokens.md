## Semantici
| Token | Riferimento | Uso |
|---|---|---|
| `color-primary` | `color-blue-500` | Azioni principali |
| `color-danger` | | Errori, azioni distruttive |
| `space-section` | | Spazio tra sezioni |

## Scala z-index
| Token | Valore | Uso |
|---|---|---|
| `z-base` | 0 | Contenuto base |
| `z-sticky` | 10 | Header, barre fisse |
| `z-dropdown` | 20 | Dropdown, tooltip |
| `z-overlay` | 30 | Overlay, drawer |
| `z-modal` | 40 | Modali |
| `z-toast` | 50 | Notifiche |
