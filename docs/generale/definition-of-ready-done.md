# Definition of Ready e Definition of Done

<!-- Fase 8 della guida. Decise una volta dal team, valgono per tutti i requisiti. -->

## Definition of Ready
Un requisito è pronto per essere sviluppato quando:

- [ ] ha criteri di accettazione;
- [ ] il flusso è completo, con le sfighe gestite;
- [ ] schermate e testi definitivi esistono;
- [ ] gli endpoint sono specificati;
- [ ] non ci sono domande aperte.

## Definition of Done
Un requisito è finito quando:

- [ ] tutti i criteri di accettazione sono superati;
- [ ] il codice è stato rivisto da un collega;
- [ ] i test sono scritti e passano;
- [ ] l'accessibilità è verificata;
- [ ] la documentazione è aggiornata e lo storico registrato;
- [ ] le modifiche visibili agli utenti sono in `CHANGELOG.md`.
