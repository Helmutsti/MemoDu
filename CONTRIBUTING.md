# Come contribuire

## Prima di iniziare
Il progetto segue il metodo descritto in `docs/guida-documentazione.md`. Leggi almeno il README della guida.

## Proporre un'idea
Aggiungi una riga in `docs/registri/idee.md` con stato *Proposta*. Il team la valuta nella revisione periodica del registro.

## Proporre una decisione
Copia `docs/registri/decisioni/_modello.md`, rinominalo con il numero successivo (`DEC-0X-titolo.md`) e compilalo con stato *Proposta*.

## Aggiungere un modulo
Copia la cartella `docs/moduli/_modello-modulo/` e rinominala con il nome del modulo (minuscole, parole separate da trattini).

## Codice e documentazione
- Se una modifica cambia un comportamento documentato, aggiorna la documentazione nella stessa pull request.
- Aggiungi una riga in `docs/registri/storico.md` per ogni modifica alla fotografia.

## Commit e pull request
- Inizia il messaggio di commit con i codici coinvolti: `RF-07 FL-07: gestione annullamento entro 24h`.
- Nella pull request elenca i documenti aggiornati e i codici collegati.

## Nomi dei file
Minuscole, parole separate da trattini, niente spazi né accenti.
